# ImProto - Front End
A prototype created to learn how to create a responsive front-end using React and other related technologies.<br>
The front-end counterpart for ImProto, which can be found at:<br>
[GitHub](https://github.com/FelNg/ImProto-Back) | [Codeberg](https://codeberg.org/telios/ImProto-Back)

---

## Technologies 
**Created using:**
- Vite and React

---

## Functionality
**Implemented so far:**
- A dynamic data table made from a static .json file.

**To be implemented:**
